# AGENTS.md: apps/mobile

Read the root [`AGENTS.md`](../../AGENTS.md) and
[`docs/COLLABORATION.md`](../../docs/COLLABORATION.md) first.

This is an Expo SDK 57 / React Native 0.86 app.

- Routes live in `src/app/` (Expo Router). Non-route code lives in `src/components`, `src/engine`, `src/features`, `src/lib`, `src/theme`.
- `src/engine/` is pure TypeScript with no React Native imports, so it can be unit-tested in Node. Keep it that way.
- The model artifact `assets/model/hoshiyar-model.json` is generated by `ml/training/train.py`. Don't hand-edit it.
- Install native packages with `npx expo install <pkg>`. If api.expo.dev is unreachable, use `EXPO_OFFLINE=1 npx expo install <pkg>`, which resolves versions from `expo/bundledNativeModules.json`.
- Never create or edit `android/` / `ios/` by hand (Continuous Native Generation).
- Before declaring done: `npm run typecheck && npm run lint && npm test`.
